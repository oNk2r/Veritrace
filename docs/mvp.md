# Veritrace MVP

## Goal

An AI-powered platform that verifies sustainability claims by comparing corporate ESG disclosures with independent emissions data.

---

## User Flow

Upload ESG Report (PDF)
        ↓
Extract Text
        ↓
AI extracts emissions data
        ↓
Fetch Climate TRACE data
        ↓
Compare datasets
        ↓
Generate AI discrepancy report
        ↓
Display dashboard

## Must Have

- Upload ESG Report
- AI JSON extraction
- Climate TRACE integration
- Comparison engine
- AI explanation
- Dashboard

## Nice to Have

- Company search
- Interactive charts
- Facility map
- Trust score
- AI Chat

## Skip

- Authentication
- Payments
- Admin Panel
- Notifications
